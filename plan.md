Project Name: Glossy
Project Goal: To build an interactive linguistic visualization web app that bridges Old English and Modern English.
Core Concept: In Old English study, a 'gloss' is a translation or explanatory note written in a text. Glossy digitizes this concept into a 'visual gloss' UI. Users will read an Old English text and interact with difficult words to reveal 'marginal glosses'—translations, grammatical functions, and explanatory notes that help them understand the text as they read.
Inspiration: The annotated Alice in Wonderland from oldenglishaerobics.net.
